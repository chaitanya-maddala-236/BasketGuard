# Design system

BasketGuard uses its own forest-green and warm-neutral identity.

| Token | Value | Use |
|---|---|---|
| Forest | `#174B3D` | Main actions, brand, inventory confidence |
| Warm | `#F7F6F0` | Screen canvas |
| Ink | `#1E2924` | Primary text |
| Mint | `#DCEDE0` | Positive and selected states |
| Orange | `#FFE5CC` | Replacement prompts |
| White | `#FFFFFF` | Product and content cards |

Cards use generous rounded corners, subtle elevation, clear quantity controls, and large category-tinted product illustrations. Availability is explicit, and replacement actions are presented as customer choices.
